# Windows setup

The portable installation and troubleshooting guide is now at [docs/WINDOWS.md](docs/WINDOWS.md).

- Install the app: run `setup.cmd`.
- Start or reopen: run `Start-Video-Content-Extractor.cmd`.
- Optional local speech: run `setup-douyin.cmd`, then restart the app and refresh the page.
- Stop this installation: run `Stop-Video-Content-Extractor.cmd`.

Open **http://127.0.0.1:8000** after starting. See [VERIFICATION.md](VERIFICATION.md) for recorded tests and their limits. This file contains no machine-specific paths, proxy configuration, or account data.
